tanpz (19/11/2026) wants Forja galleries and screens presented the way component/template marketplaces present motion: live-preview cards, rankings, sections with "Ver tudo", category chips. He said some sites are "muito melhores" than 21st.dev. He mentioned "ConfUI", which was not found; it is probably ComfyUI or a misheard name, so ask him once.

Verified 19/11:
- 21st.dev/community/components: grouped sidebar with counts, category chips, Featured/Newest sort, horizontal rows with "View all".
- skiper-ui.com: cards with a looping video thumbnail and a Free/Premium tag. This is the hover-video pattern.
- ui.aceternity.com: sections with title, count and "Show more"; template cards with "Live Preview".
- kokonutui.com (MIT): AI components such as the model selector and chat bar. Base for a Higgsfield-style generate bar.
- cult-ui.com (MIT): cards and device mockups.
- magicui.design, reactbits.dev, shadcnblocks.com, coss.com/ui (formerly Origin UI), mobbin.com (settings and onboarding flows).

None of these ships a ready numbered ranking ("Top hoje"); we build our own. See [[feedback-21st-sempre]], [[maquina-v2-produto]].
