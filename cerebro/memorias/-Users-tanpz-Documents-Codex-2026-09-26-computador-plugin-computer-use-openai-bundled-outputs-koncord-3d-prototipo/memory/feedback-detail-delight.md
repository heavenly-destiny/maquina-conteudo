KONCORD is a game experience, not a demo: the owner wants players to go "caramba, ele pensou nisso" at every turn. Sounds must be believable and subtle (e.g. typing only when someone sits at a computer, very soft, fading with distance), UI minimal (popups: one centered action + an X in the top-right corner).

**Why:** the owner repeatedly flags things that break immersion (sounds with no source, too loud, unsynced steps, clutter).

**How to apply:** for every feature, ask "what would a real place/AAA game do?" — tie effects to real sources, add proximity falloff, keep volumes low, and trim UI to the essential. Pairs with [[feedback-ready-made-first]].
