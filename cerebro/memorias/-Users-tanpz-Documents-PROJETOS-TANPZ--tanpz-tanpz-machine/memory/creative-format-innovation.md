Each new creative needs a new **format**, not only new copy. Repeating the template of earlier pieces gets rejected.

**Why:** on 2026-11-16 the user said of creative 4: "parece todos os outros, cadê inovação, formato". It reused the cream background, phone in the middle and white caption on top. They loved the split-screen race (5) and chose the friends' chat with voice notes for the redo.

**How to apply:**
- Before writing copy, list the formats already used in the set and pick one that is not there. Options: a friends' chat with voice notes, a split-screen race, a lock screen where notifications tell the story, a raw screen recording with Instagram's hand-drawn text, a POV routine with clocks, a DM "print" story, and others.
- When proposing, pitch 2–3 format ideas in one line each and recommend one.
- The format itself should look native to the phone (chat, notifications, screen recording), because native formats stop the scroll better than "ad" layouts.
