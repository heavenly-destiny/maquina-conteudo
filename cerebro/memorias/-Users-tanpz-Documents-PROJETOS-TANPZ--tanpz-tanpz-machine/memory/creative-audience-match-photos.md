All imagery in a creative must match the target audience. The Stories Lab audience is women, so nothing male can appear: no men's hands, cars or car keys (e.g. BMW), no men's trousers or clothing.

**Why:** on 2026-11-16 the user was angry ("não pode usar uma foto masculina de um carro num criativo feminino") because `sl-ugc/assets/photos/latte.jpg` showed a man's hand holding iced coffee in a BMW. It had been used as "her story" in the UGC creatives. The filename suggested coffee, so it was never visually checked.

**How to apply:**
- Never pick a photo by its filename. Before using any stock or Pinterest photo, build a contact sheet and look at it.
- Reject anything with male cues or anything off-audience.
- `photos/latte.jpg` is now banned. Use `photos/plaincoffee.jpg` (pink pyjamas with coffee) or a site story instead.
