# Cinco motores de ascensão rodando em paralelo — e o lançamento é o mais fraco

Parte de [[Ecossistemas 7D]].

- Os cinco motores usados pra subir alunos do front pro back end/high-end: (1) upsell imediato — logo após a compra; (2) workshop semanal ao vivo — aula diferente do webinário diário, com foco comercial; (3) webinário diário gravado — funciona como um "upsell imediato repetido", ver [[12-workshop-ao-vivo-recencia-do-convite-aumenta-comparecimento]]; (4) formulário de matrícula + time comercial — ver [[13-formulario-de-matricula-como-fonte-de-leads-comerciais]]; (5) lançamento pago, 5x/ano, também chamando a base de alunos do front.
- Dado revelador: o lançamento, mesmo sendo o motor histórico do negócio, é hoje o que **menos** converte alunos pra ascensão — porque quando o lançamento acontece, a maior parte da base já foi "acesa" pelos outros quatro motores antes.
- Impacto agregado medido: tirando toda ascensão do jogo (só front + upsell imediato), o ROI do funil fica em 1,6-1,7. Somando os cinco motores de ascensão, o ROI final sobe pra 3,2-3,3 — quase o dobro.
- Regra por trás disso: nunca depender de uma estratégia só pra acender a base — cada motor pega quem escapou dos outros (quem não comprou no webinário diário, compra no workshop; quem não foi no workshop, é abordado pelo comercial via formulário; etc).
- Princípio citado do livro *The Marketing Rebellion*/Todd Brown: "pro marqueteiro experiente não existe diferença entre conteúdo e marketing" — todo ponto de contato (aula, bônus, mensagem de boas-vindas) é desenhado como uma ponte pra próxima etapa de ascensão, não só como entrega de valor isolada.
