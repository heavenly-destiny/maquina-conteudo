# A tabela de modelagem: duas colunas para bater o controle sem ripar nem recriar do zero

Parte de [[Ecossistemas 7D]].

- Documento simples (texto corrido, sem células de planilha): coluna 1 recebe o anúncio original transcrito inteiro; coluna 2 recebe o anúncio novo sendo escrito a partir dele.
- Processo: ler o original parágrafo por parágrafo e entender o que cada trecho está fazendo (é uma prova? uma curiosidade? uma quebra de objeção?). Ela mesma marca essas funções com cores no documento.
- Regra central: não é preciso usar as mesmas palavras do original, mas é preciso dizer exatamente o que ele quis dizer — mantendo a função de cada bloco, mas podendo reforçar a prova (de "pessoas usaram e funcionou" para "mais de 40.000 pessoas testaram durante X tempo e relataram Y"), inverter a ordem dos blocos, ou inserir um CTA no meio do texto onde antes só havia um no final.
- É a ferramenta que recomenda para todo iniciante e que hoje usa para treinar os próprios copywriters do time.
