# Estrutura invisível: modele os elementos dentro do bloco, não só a ordem macro

Parte de [[Ecossistemas 7D]].

- Além da estrutura macro da VSL (lead → história → mecanismo → oferta), existe uma "estrutura invisível" dentro de cada bloco: a sequência específica de elementos (depoimento, promessa, benefício, toque na dor etc.) que aparecem naquele bloco, e em que ordem.
- Processo prático: ler a VSL de referência frase por frase e marcar cada elemento num Google Docs com comentários curtos ("isso aqui é depoimento", "isso é uma promessa"...) até ter a sequência completa de elementos de cada bloco.
- Por que funciona: pessoas de um mesmo nicho compartilham os mesmos desejos, medos e objeções — seguir a mesma ordem de elementos significa quebrar as mesmas objeções, na mesma sequência que já provou funcionar, só que com palavras próprias.
- Não é copiar, é modelar por elemento: "começa com depoimento? Você começa com um depoimento seu. Vem uma promessa? Você faz uma promessa sua." A ordem importa mais que as palavras exatas.
- Termo usado por Allan Sultanik (também citado no livro *Copywriting Crash Course*); pouco conhecido no Brasil, muito usado pelos americanos.

> "O que faz a cópia vender é a ordem que as informações estão nela. Se você coloca as informações naquela ordem, ela vai vender. Se você não coloca, ela não vai vender ou tem uma chance muito mínima de vender."
