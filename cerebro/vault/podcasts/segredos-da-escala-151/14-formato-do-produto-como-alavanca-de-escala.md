# O formato do produto pode ser uma alavanca de escala maior que a própria copy

Parte de [[Ecossistemas 7D]].

- Case citado: mesmo mecanismo, mesma copy — só o formato do produto mudou (de cápsula pra gotas) e a VSL saiu de R$100-200 mil/dia para R$800-900 mil, chegando a R$1 milhão/dia.
- Como testam formato sem comprometer logística própria: a operação roda ofertas também como afiliada, aproveitando o relacionamento com outros produtores — pedem pra trocar o formato de um produto já existente (cápsula → pounder, por exemplo) pra validar rápido se aquele formato bate o controle antes de produzir algo novo.
- Dentro do product buildup, abrem um bloquinho curto no estilo "econ" justificando o formato escolhido (cápsula: absorção maior via digestão estomacal; pó/pounder: sabor prazeroso que transforma o "ritual" de consumo) — esse bloco é reescrito toda vez que um teste A/B de formato é feito.
- Ranking de importância do próprio convidado: o bloco de product buildup em si não é 8020 da oferta escalar, mas a decisão de qual formato de produto usar é uma das decisões de maior alavancagem dentro desse bloco.

> "Vai ser a diferença da sua VSL sair de 100, 200 mil para começar a fazer 800, 900, 1 milhão por dia ali."
