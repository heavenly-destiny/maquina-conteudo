# Documentar o processo como piso mínimo, não como teto

Parte de [[Ecossistemas 7D]].

- A primeira contratação (irmão como editor, primo como copywriter) foi treinada com um documento simples escrito pelos próprios fundadores no Notion: passo A, passo B, passo C — "não sai disso daqui".
- Só depois que a pessoa dominava executar exatamente aquele processo documentado é que era liberada para buscar formas diferentes ou melhores de fazer a mesma tarefa.
- A distinção prática: o documento define o piso mínimo aceitável de qualidade, não o teto do que a pessoa pode desenvolver depois.
- Pré-requisito citado pelos dois: quem escreveu o processo precisava já saber executá-lo pessoalmente antes de ensinar (ex.: Hugo editava manualmente no CapCut antes de documentar o processo pro irmão).

> "Quando a gente fala que a gente passou o processo, era tipo assim, é a base — é de onde, tipo, daqui para baixo você não pode, mas daqui para cima tá liberado."
