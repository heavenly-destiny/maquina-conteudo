# Motor de pós-venda: os 3 pilares

Princípio: todo problema que você resolve para um cliente gera um novo problema — exemplo dado, resolveu o problema do cliente gordo (emagreceu); agora ele quer cuidar da pele, a roupa velha parou de servir, ele quer namorar. Cada um desses é uma nova oferta possível pra base já comprada.

3 pilares pra monetizar essa cadeia: (1) **coleta de dados** do cliente (pesquisa, CRM, dado organizado); (2) **equipe responsável** por identificar o momento certo de oferecer o próximo passo; (3) um **produto bom o suficiente** pra de fato resolver o problema original — sem isso não existe "próximo problema" legítimo pra vender. Complementa o [[pesquisa-continua-motor-de-produto|motor de pesquisa contínua]], que é o mecanismo específico de descobrir, via pesquisa, qual é exatamente o próximo produto certo pra oferecer.
