# Cálculo de teto teórico de funil

Modelo mental para decidir se vale investir tempo do especialista (recurso mais escasso) numa ação nova ou apenas escalar o que já está validado.

## Fórmula

```
base → % que entra no grupo → % de comparecimento → % de conversão no pitch → ticket = teto de faturamento
```

Exemplo usado como demonstração ao vivo: 50 tickets/dia → 80% entram no grupo (40) → 30% de comparecimento (12) → 10% de conversão no pitch (~1,2 venda) → escalado por 30 dias e por um volume maior (100/dia) para projetar faturamento mensal.

## Uso

- Calcular o **teto teórico** (se toda conversão fosse 100%) antes de comprometer o tempo do especialista numa ação — serve pra saber se vale a pena antes de gastar o recurso mais escasso do negócio.
- Critério de decisão final é sempre **lucro do funil**, nunca faturamento bruto — um funil de alto faturamento e baixa margem pode valer menos que um funil pequeno e lucrativo.
- Usado tanto para decidir entre lançar uma nova ação de [[funil-de-ascensao]] quanto para decidir se um produto merece virar perpétuo (ver [[webinarios-tipos-e-frequencia]]).
