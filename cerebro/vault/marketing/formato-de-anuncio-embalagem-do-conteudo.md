# Formato de anúncio: a embalagem do conteúdo

O formato é a forma como o conteúdo do criativo está embalado — não o conteúdo em si. A mesma cópia pode virar uma resposta de caixinha de pergunta, um corte de podcast, um FaceTime fingido, uma entrevista, ou até um clone de IA falando, sem mudar uma palavra do que é dito.

Descobre-se quais formatos testar observando o que o público-alvo já consome organicamente — via [[perfil-espiao-para-medir-o-pulso-do-mercado|perfil espião]] ou só acompanhando o conteúdo orgânico do nicho.

Cuidado central: copiar o formato de quem já é famoso não funciona da mesma forma para quem não tem a mesma fama — ver [[gancho-visual-vs-narrativo-e-formato-guruzao]].
