# Squads dedicados por nicho (copywriter + editor fixos)

Modelo organizacional para operações de alto volume de criação de oferta: em vez de um pipeline linear genérico (todo copywriter/editor atende qualquer nicho), formam-se squads fixas por nicho — um grupo de nichos parecidos (ex.: emagrecimento + diabetes) fica sob a mesma dupla/equipe de copywriter e editor, repetidamente, ao longo de várias ofertas.

Dois efeitos buscados com isso:

- **Especialização de conteúdo**: quem escreve sempre o mesmo tipo de nicho desenvolve fluência mais rápido do que quem alterna de nicho a cada oferta — reduz a curva de aprendizado a cada novo projeto.
- **Especialização de relacionamento**: a mesma dupla copywriter+editor trabalhando repetidamente junta desenvolve vocabulário e confiança mútua — o editor passa a entender a intenção do copywriter com menos explicação a cada ciclo (ver [[briefing-documentado-copywriter-editor]]).

Analogia usada para justificar o modelo: uma rede de supermercados negocia compra em volume centralizado, mas cada loja mantém equipe e cultura próprias — a especialização local do time pequeno supera um modelo 100% padronizado/linear. O trade-off é que o modelo exige estrutura mínima (múltiplas pessoas por função) para comportar a divisão — abaixo de certo tamanho de equipe, o modelo linear ainda é mais simples de gerir.
