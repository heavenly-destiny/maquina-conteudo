# Playbook: Como Criar uma Oferta do Zero

Parte de [[Ecossistemas 7D]].

Síntese acionável — não duplica o conteúdo das notas atômicas, só define a ordem certa de passar por elas. Cada fase linka direto pra nota que ensina o "como". Se quiser o processo guiado interativo em vez de ler, o skill `hormozi-offer` já disponível neste ambiente cobre a mesma sequência com perguntas passo a passo. Depois de desenhar a oferta aqui, o funil que vai entregá-la (quiz + mini-VSL) está em [[Como Criar um Funil de Quiz do Zero]], e o roteiro de VSL bloco a bloco está em [[Como Escrever uma VSL do Zero]].

## Fase 0 — Mercado e avatar (antes de desenhar qualquer produto)

- [ ] Mercado é endereçável o suficiente? → [[../marketing/criterio-mercado-enderecavel]]
- [ ] Modelo de negócio bate com o que você tem (DFY/DWY/DIY, ticket, recorrência)? → [[../marketing/criterios-de-escolha-de-modelo-de-negocio-digital]]
- [ ] Se tem um especialista por trás, ele está sendo usado onde é insubstituível? → [[../marketing/zona-de-genialidade-do-especialista]]
- [ ] Lembrete de peso: 40% público, 40% oferta, só 20% copy — não adianta refinar copy em cima de público errado → [[../marketing/framework-40-40-20-publico-oferta-copy]]

## Fase 1 — Desenhar o produto de entrada

- [ ] Produto está no topo de funil certo pro seu mercado (não subnicho demais)? → [[../marketing/produto-topo-de-funil]]
- [ ] Se for produto de entrada de VSL: uma dor única, urgente, em formato de desafio → [[../marketing/produto-de-entrada-dor-unica-formato-desafio]]
- [ ] Decisão de mecanismo — próprio, validado ou novo? Três lentes complementares:
  - [[../marketing/mecanismo-proprio-em-vez-de-seguir-tendencia]]
  - [[../marketing/mecanismo-validado-vs-mecanismo-novo]]
  - [[../marketing/mecanismo-simples-e-credivel-do-expert]] (nicho cético pede mecanismo simples, não mirabolante)
- [ ] Se o mecanismo for radicalmente novo, ele pede o enquadramento de categoria própria → [[../marketing/novo-veiculo-de-oportunidade]]
- [ ] Não gaste ciclo otimizando lead/criativo pra salvar oferta fraca — oferta ruim não se conserta depois → [[../marketing/oferta-boa-nasce-boa]]

## Fase 2 — Aplicar a Equação de Valor

- [ ] Rodar a Equação de Valor no produto (Resultado dos Sonhos × Percepção de Probabilidade, dividido por Tempo até o resultado × Esforço/Sacrifício) → [[../marketing/equacao-de-valor-para-iterar-produto]]
- [ ] Categorizar o mecanismo em pilares — tangibiliza a oferta, resolve "retenção alta mas não converte" → [[../marketing/construcao-de-produto-em-pilares-tangibiliza-mecanismo]]
- [ ] Prometer menos do que o produto entrega de verdade, de propósito — deixa lacuna pro backend → [[../marketing/promessa-comedida-deixa-lacuna-pro-backend]]
- [ ] Projetar linha do tempo de resultado de forma concreta (reduz percepção de "tempo até o resultado") → [[../marketing/linha-do-tempo-de-resultado-projetada]]

## Fase 3 — Empilhar valor (stack)

- [ ] Montar o stack visual: nome → problema que resolve → valor declarado → "hoje, de graça" → [[../marketing/stack-slide-empilhamento-visual-de-oferta]]
- [ ] Cada bônus com valor percebido explícito e prazo → [[../marketing/bonus-com-valor-percebido-e-prazo]]
- [ ] Se o bônus for do mesmo produto (não complementar), considerar reformular desconto como quantidade "grátis" → [[../marketing/compre-x-leve-y-gratis]]
- [ ] Nomear cada item do stack como fascination (curiosidade + benefício), não descrição plana → [[../marketing/fascinations-bullets-de-desejo]]

## Fase 4 — Precificar e ancorar

- [ ] Calibrar ticket pela faixa que já validou no seu nicho/formato → [[../marketing/precificacao-de-vsl]]
- [ ] Ancorar contra o item mais caro da esteira/concorrência → [[../marketing/ancoragem-de-preco-por-comparacao]]
- [ ] Duas rotas de pagamento no fechamento (pagar menos agora vs. pagar depois) pra atacar resistência de preço e de compromisso ao mesmo tempo → [[../marketing/pague-menos-agora-ou-mais-depois]]
- [ ] Se a oferta for um upgrade de algo já comprado, creditar o que já foi pago → [[../marketing/ladder-de-produtos-com-abatimento-do-ja-pago]]

## Fase 5 — Reduzir risco (garantia)

- [ ] Garantia além do mínimo legal, apresentada retoricamente (mínimo → prazo estendido) → [[../marketing/garantia-alem-do-minimo-legal]]
- [ ] Se for modelo de trial/continuidade: considerar cobrança condicionada a regra não cumprida, em vez de reembolso padrão → [[../marketing/trial-com-penalidade]]

## Fase 6 — Escassez, urgência e estrutura da decisão

- [ ] Fechamento com custo de oportunidade + "3 caminhos" (ficar como está / tentar sozinho / sua oferta) → [[../marketing/custo-de-oportunidade-e-tres-caminhos]]
- [ ] Qualificação negativa explícita — dizer pra quem NÃO é, aumenta conversão de quem é → [[../marketing/qualificacao-negativa-nao-e-pra-todo-mundo]]
- [ ] Estruturar a decisão como escolha entre opções pré-desenhadas (planos/order bump/upsell sim-sim), nunca "compra ou não compra" solto → [[../marketing/controle-de-opcoes-em-oferta]]

## Fase 7 — Nomear a oferta

- [ ] Nome chiclete + validação por teste seco antes de comprometer produção → [[../marketing/nome-chiclete-e-teste-seco]]

## Fase 8 — Pensar no backend antes de lançar o fronte

Uma oferta isolada é só 1/3 do jogo — o mapa completo:

- [ ] Onde essa oferta entra no ecossistema (aquisição, recompra ou ascensão)? → [[../marketing/framework-ecossistema-de-funis]]
- [ ] Se for produto de recompra: nunca revender o que já foi prometido na entrada → [[../marketing/funil-de-recompra]]
- [ ] Se for produto de ascensão: ticket mais alto, é onde mora a maior parte do lucro → [[../marketing/funil-de-ascensao]]
- [ ] Se tiver componente de continuidade: ciclo de cobrança a cada 28 dias em vez de por calendário → [[../marketing/hack-do-13o-mes-ciclo-de-cobranca]]
