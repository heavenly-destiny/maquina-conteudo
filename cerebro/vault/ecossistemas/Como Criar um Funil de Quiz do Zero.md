# Playbook: Como Criar um Funil de Quiz do Zero

Parte de [[Ecossistemas 7D]].

Síntese acionável — não duplica o conteúdo das notas atômicas, só define a ordem certa de passar por elas. Complementa [[Como Criar uma Oferta do Zero]]: monte a oferta primeiro (o que você vende), depois use este playbook pra construir o funil que entrega essa oferta via quiz + mini-VSL.

## Fase 0 — Antes de montar o quiz

- [ ] Mercado é endereçável o suficiente pro volume que um quiz exige? → [[../marketing/criterio-mercado-enderecavel]]
- [ ] Produto de entrada está no nível certo de topo de funil (não subnicho demais)? → [[../marketing/produto-topo-de-funil]]
- [ ] Confirmar que quiz + mini-VSL é o formato certo pra esse caso — é um dos dois formatos de funil de aquisição do ecossistema, o outro é VSL direta → [[../marketing/funil-de-aquisicao]]

## Fase 1 — Estrutura macro do funil

- [ ] Onde o quiz fica hospedado/linkado — página central que recebe tráfego de qualquer canal, não um site institucional → [[../marketing/funil-hub-pagina-central-de-distribuicao]]
- [ ] Calibrar o nível de consciência do público que cada canal traz — quem vem de anúncio frio não está no mesmo ponto de quem vem de conteúdo orgânico → [[../marketing/escada-de-consciencia-do-lead]]
- [ ] O tráfego chega carregando o comportamento da plataforma de origem (Meta = dopamina rápida/baixa consciência; YouTube = busca ativa/mais paciência) — o quiz precisa respeitar isso desde a primeira tela → [[../marketing/lead-deve-simular-comportamento-da-plataforma-de-origem]]

## Fase 2 — Primeira etapa do quiz (a que mais importa)

- [ ] Headline de benefício direto + imagem + CTA de "iniciar diagnóstico" + escassez logo abaixo do botão → [[../marketing/primeira-etapa-do-quiz-formula]]
- [ ] Primeira pergunta confirma um dado óbvio (gênero/idade/objetivo) — cria sensação de exclusividade e já começa a segmentar → [[../marketing/qualificacao-por-genero-como-filtro]]

## Fase 3 — Corpo do quiz (etapas de diagnóstico)

- [ ] Cada etapa faz a pessoa articular o próprio sintoma antes de qualquer explicação do mecanismo → [[../marketing/autodiagnostico-no-quiz]]
- [ ] Não ter medo de alongar — quizzes de 30-50+ etapas convertem melhor que versões curtas, desde que sejam interativos (não existe funil longo, existe funil chato) → [[../marketing/extensao-do-quiz-mais-etapas-mais-conversao]]
- [ ] As perguntas do quiz já vão semeando a crença única que a VSL vai fechar depois → [[../marketing/formula-de-lead-tres-perguntas-e-one-belief]]

## Fase 4 — Fechamento do quiz → ponte pra oferta

- [ ] Última pergunta pede compromisso verbal explícito antes de liberar a VSL ("você se compromete a assistir até o final?") → [[../marketing/micro-compromisso-antes-do-pitch]]
- [ ] Se o produto tiver camada de ascensão comercial: usar um formulário de matrícula logo no primeiro módulo como pesquisa disfarçada de qualificação → [[../marketing/formulario-de-matricula-como-fonte-de-leads-comerciais]]

## Fase 5 — A mini-VSL que o quiz libera

- [ ] Em low ticket, considerar duas mini-VSLs curtas (1-2 min cada) em vez de uma só — uma de credibilidade, outra só de oferta → [[../marketing/duas-mini-vsls-credibilidade-e-oferta]]
- [ ] A lead é trailer, não informação — promessa + segmentação + prova + curiosidade, nunca entrega o conteúdo de fato → [[../marketing/lead-como-trailer-teste-de-angulos]]
- [ ] Escrever a lead a partir dos elementos validados de um criativo que já escala (avatar, formato, prova, ordem dos gatilhos), não copiando a história literal → [[../marketing/elementos-do-criativo-para-a-lead]]
- [ ] Multiplicar variações sem perder a psicologia já validada no resto do vídeo → [[../marketing/variacao-de-microlead]]
- [ ] Estrutura completa de VSL (lead → mecanismo → oferta), engenharia reversa e benchmarks → [[../marketing/processo-de-vsl-engenharia-reversa]]
- [ ] Roteiro completo da VSL, bloco a bloco → [[Como Escrever uma VSL do Zero]]
- [ ] Se a oferta em si ainda não estiver desenhada, voltar pro → [[Como Criar uma Oferta do Zero]]

## Fase 6 — Tráfego pro quiz

- [ ] Mapear os 4 canais fundamentais de geração de lead (quente/frio × 1-1/1-muitos) → [[../marketing/core-four-quatro-canais-de-geracao-de-leads]]
- [ ] Mapear onde seu público já está reunido antes de gerar conteúdo do zero → [[../marketing/dream-100-mapeamento-de-publico-ja-reunido]]
