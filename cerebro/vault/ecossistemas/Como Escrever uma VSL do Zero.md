# Playbook: Como Escrever uma VSL do Zero

Parte de [[Ecossistemas 7D]].

Síntese acionável — não duplica o conteúdo das notas atômicas, só define a ordem certa de passar por elas. A sequência segue a ordem real e validada de [[../paginas/bumbumflix-gluteo/Bumbum Flix|um funil já no ar]] (15 blocos, ponto por ponto). Pressupõe que a oferta já foi desenhada em [[Como Criar uma Oferta do Zero]] e que a VSL vai ser entregue por um funil como o de [[Como Criar um Funil de Quiz do Zero]].

## Fase 0 — Pesquisa antes de escrever uma linha

- [ ] Engenharia reversa: 2-3 VSLs que já vendem no mesmo nicho, critério de saturação, benchmarks de retenção/duração → [[../marketing/processo-de-vsl-engenharia-reversa]]
- [ ] Extrair a estrutura invisível (sequência de elementos, não as frases) da VSL de referência → [[../marketing/estrutura-invisivel-de-copy]]

## Fase 1 — Lead / Hook (os primeiros 30-60 segundos)

- [ ] A lead é trailer, não informação: promessa + segmentação + prova + curiosidade → [[../marketing/lead-como-trailer-teste-de-angulos]]
- [ ] Testar a fórmula das três perguntas (por que é novo / o que tem aqui pra mim / como eu provo) + a crença única → [[../marketing/formula-de-lead-tres-perguntas-e-one-belief]]
- [ ] Escrever a partir dos elementos validados de um criativo que já escala, não copiando a história literal → [[../marketing/elementos-do-criativo-para-a-lead]]
- [ ] Intensificar cada elemento do hook com especificidade concreta → [[../marketing/densidade-psicologica-do-hook]]
- [ ] Multiplicar variações de microlead sem perder a psicologia já validada → [[../marketing/variacao-de-microlead]]

## Fase 2 — Regras + prova social inicial

- [ ] Anunciar regras explícitas logo na abertura — neutraliza objeção antes dela aparecer → [[../marketing/regras-do-desafio-como-neutralizador-de-objecoes]]
- [ ] Prova social em formato de feed de comentários reais → [[../marketing/prova-social-em-feed-de-comentarios]]

## Fase 3 — Mecanismo único / tese central

- [ ] Cristalizar a crença única numa frase: [nova oportunidade] é a chave para [desejo], através de [mecanismo] → [[../marketing/one-belief-formula-de-crenca-unica]]
- [ ] Construir a cadeia de 5-8 pontos lógicos que prova essa frase, passo a passo → [[../marketing/pontos-logicos-como-tese-de-marketing]]
- [ ] Estrutura completa lead→mecanismo→oferta → [[../marketing/framework-mecanismo-de-vsl]]
- [ ] Escolher o ângulo narrativo de entrada pro mecanismo → [[../marketing/angulo-de-mecanismo]]
- [ ] Se o nicho já tem um "vilão" recorrente, nomeá-lo formalmente → [[../marketing/gatilho-do-inimigo-nomeado]]
- [ ] Atacar o método mais óbvio/conhecido do nicho com argumento técnico real → [[../marketing/quebra-de-mito-do-obvio]]

## Fase 4 — Credibilidade do especialista

- [ ] Vulnerabilidade estratégica em vez de perfeição → [[../marketing/autoridade-por-vulnerabilidade-estrategica]]
- [ ] Se a oferta usa expert real: vantagens (marca dupla, backend, credibilidade anti-IA) e riscos → [[../marketing/expert-real-vantagens-e-riscos]]
- [ ] Puxar uma "super estrutura" (pessoa/marca/elemento já validado na crença do público) se houver uma disponível → [[../marketing/super-estrutura-elemento-de-prova]]

## Fase 5 — Bloco de história

- [ ] Ponte da Epifania: desejo/backstory → parede nomeada → momento da epifania com detalhe sensorial → plano → conquista → [[../marketing/ponte-da-epifania-epiphany-bridge]]
- [ ] Escolher a fonte da história (a sua própria epifania, a de um cliente, ou a jornada de descoberta do método) → [[../marketing/tres-fontes-de-historia-em-vsl]]

## Fase 6 — Reciprocidade + prova em massa + reframe

- [ ] Entregar conteúdo real e completo no meio da VSL, antes do pitch → [[../marketing/reciprocidade-por-conteudo-gratis-no-vsl]]
- [ ] Prova em formato de reportagem/mídia nativa, crua, sem cinematografia → [[../marketing/prova-midiatica-nativa-como-formato-de-criativo]]
- [ ] Depois da prova social, deslocar a culpa do fracasso passado do cliente pro "sistema" → [[../marketing/reframe-de-culpa-do-cliente-para-o-sistema]]
- [ ] Aprofundar cada benefício em três camadas: funcional, dimensional, emocional → [[../marketing/beneficios-funcionais-dimensionais-emocionais]]

## Fase 7 — Revelação do produto e oferta

- [ ] Mecanismo do problema → mecanismo da solução → prova (+ autoridade opcional) → [[../marketing/estrutura-de-conteudo-mecanismo-prova-autoridade]]
- [ ] Categorizar o mecanismo em pilares pra tangibilizar o produto → [[../marketing/construcao-de-produto-em-pilares-tangibiliza-mecanismo]]
- [ ] A partir daqui, seguir o stack/preço/garantia/escassez completo em → [[Como Criar uma Oferta do Zero]]

## Fase 8 — Objeções e fechamento

- [ ] Objeções como mensagens reais de clientes nomeados, não FAQ genérico → [[../marketing/objecoes-como-mensagens-reais-de-clientes]]
- [ ] Qualificação negativa explícita → [[../marketing/qualificacao-negativa-nao-e-pra-todo-mundo]]
- [ ] Custo de oportunidade + "3 caminhos" → [[../marketing/custo-de-oportunidade-e-tres-caminhos]]
- [ ] Nunca fechar numa única chamada — sequência escalonada de CTAs até o reforço final → [[../marketing/chamada-com-multiplos-ctas-escalonados]]

## Fase 9 — Formato e execução

- [ ] O formato certo é o que casa com o hábito de consumo do público, não o mais viral → [[../marketing/formato-deve-casar-com-habito-de-consumo-do-publico]]
- [ ] Naturalidade supera produção perfeita → [[../marketing/naturalidade-supera-producao-perfeita-em-vsl]]
