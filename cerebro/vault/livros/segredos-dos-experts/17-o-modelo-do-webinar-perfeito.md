# Segredo #17 — O Modelo do Webinar Perfeito

Parte de [[Ecossistemas 7D]].

Enquanto o Segredo #12 descreve o que é dito dentro da apresentação (o script Hook-Story-Offer), o Modelo do Webinar Perfeito é o funil ao redor dela: página de inscrição → sequência de lembrete/aquecimento → o próprio webinário ao vivo ou gravado → página de oferta/checkout com o replay disponível por tempo limitado. É a estrutura de distribuição que entrega audiência para o script rodar em escala.

A decisão de qual variante de webinário rodar dentro desse funil (perpétuo gravado, evento pago ao vivo, ou lançamento para a base) já é uma decisão de negócio — ticket, frequência, carga operacional — documentada separadamente no vault, não uma variação do script em si.
