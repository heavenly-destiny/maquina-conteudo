# Features Not Included in the Free Trial

Free Trial is designed to give every new user a chance to experience all core Pro features. However, due to product stability, resource limitations, and security considerations, a few Pro features are currently not available to trial users.

Here is a list of Pro-only features not included in the Free Trial:

* Videos exported during the trial will include the OpusClip watermark
* Trial users do not have access to the 100GB fixed cloud storage and cannot autosave projects
* Trial users cannot download multiple video files in bulk
* Trial users cannot have access to the auto censor feature
* Trial users cannot post directly to social media or schedule video posts
* Trial users cannot create team or access team relevant workspace features
* Trial users cannot add Intro and outro cards for clips
* Trial users cannot use speech/voice enhancement
* Trial users cannot access video analytics
* Trial users cannot use speaker-based caption colors to differentiate speakers in their clips
* Trial users cannot add transition effects between scenes
* Trial users cannot add music from the copyright-free music library or upload their own music
* Trial users cannot set a custom thumbnail for their clips
* Trial users cannot download or post videos in 4K
* Trial users cannot access Seedance 2.0
* Trial users cannot access Custom Style V2
* Trial users cannot reprocess a video to get a credit refund if they are not satisfied with the results
