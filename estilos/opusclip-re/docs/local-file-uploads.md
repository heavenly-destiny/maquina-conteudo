# Local File Uploads

### Can I upload local files?

You can upload a local file that's **no more than 10GB and up to 10 hours long**.

![](https://mintcdn.com/opusclip-c3e48c12/2FSMdgPPp0xAqQFI/images/imgs/local-file-uploads.png?fit=max\&auto=format\&n=2FSMdgPPp0xAqQFI\&q=85\&s=9048a326d7bb9e9d8f38c1132fb07808)

**NOTE:** Videos with non-integer frame rates are not currently supported. If your video has a non-integer frame rate, please upload it to **YouTube** first and drop the YouTube link as a workaround. YouTube will automatically convert it to a supported format.
