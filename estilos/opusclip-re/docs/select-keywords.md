# Use Prompts to Clip Specific Moments

You can prompt specific moments using ClipBasic or ClipAnything:

**ClipBasic**: Input keywords to help AI identify relevant moments in the video. Ensure the keywords are present in the speech or transcript for accurate results.

![](https://mintcdn.com/opusclip-c3e48c12/2FSMdgPPp0xAqQFI/images/imgs/keywords-1.png?fit=max\&auto=format\&n=2FSMdgPPp0xAqQFI\&q=85\&s=745b837c4056f82e5f5f2f8339e04dab)

**ClipAnything**: Use natural language prompts, sentences or keywords to locate scenes, actions, characters, events, emotional moments, viral topics, and more.
To learn more about prompts, please visit [ClipAnything Prompts Manual](https://help.opus.pro/docs/article/clip-anything-prompt-manual.md).

You can use prompts to get clips in two ways in ClipAnything:

1. Before project submission in the clips settings section:

![](https://mintcdn.com/opusclip-c3e48c12/2FSMdgPPp0xAqQFI/images/imgs/keywords-2.png?fit=max\&auto=format\&n=2FSMdgPPp0xAqQFI\&q=85\&s=15f65346b02bc8e4e21bb571f7cbb859)

2. In the result page near the top of the screen:

> [!TIP]
>
> Tip: You can reprompt as many times as you like to get more clips, if you are not satisfied with the results. You will also find suggested prompts that you can try in the input box, and clicking on it will start the process.

![](https://mintcdn.com/opusclip-c3e48c12/2FSMdgPPp0xAqQFI/images/imgs/keywords-3.png?fit=max\&auto=format\&n=2FSMdgPPp0xAqQFI\&q=85\&s=94a42823102c5919f825b57b497e35fc)
