# Adjust Layout

## Adjust Layout

To change a clip's layout, click **Layout** at the top and select one. Your layout is applied wherever it fits.

### Change the layout of a segment

To relayout a single scene, select it from the timeline, then right-click the canvas or open the **Layout** dropdown and choose a layout.

![](https://mintcdn.com/opusclip-c3e48c12/KPZfitdFkt_kwa4N/images/imgs/apply-the-layouts-1.gif?s=9b2e3dc4ac93d858c251dcb655b78a35)

### Change the layout of a B-roll segment

Segments with B-roll unlock extra framing options. Select the B-roll clip on the timeline, then right-click the canvas or open the **Layout** dropdown to pick a framing:

* **Fill** (default) fills the screen
* **Picture-in-Picture (PIP)** keeps your speaker in a small window over the B-roll
* **Split** stacks the speaker and B-roll top and bottom (not supported for 16:9)

![](https://mintcdn.com/opusclip-c3e48c12/sNFa6xRy0hcq2gSN/images/imgs/apply-the-layouts-broll-framing.gif?s=33c767fbca11a6a9ab6ebaaed9d4713c)

#### One B-roll per segment for Picture-in-Picture

Picture-in-Picture only applies to **one B-roll at a time**. If a segment contains two B-rolls, split it into separate segments on the timeline first — then apply Picture-in-Picture to each segment individually.

![](https://mintcdn.com/opusclip-c3e48c12/sNFa6xRy0hcq2gSN/images/imgs/apply-the-layouts-broll-pip-note.png?fit=max\&auto=format\&n=sNFa6xRy0hcq2gSN\&q=85\&s=9a5a7a79c850482b1730622ba3579e59)

## Set default layout

You can customize your layout preferences using your Brand Kit and apply them to your entire project before submitting it. To get started, navigate to the **Brand kit** page and create a new kit.

![](https://mintcdn.com/opusclip-c3e48c12/KPZfitdFkt_kwa4N/images/imgs/apply-the-layouts-3.gif?s=e6a3f45cc1b8aa975bbe511c98f3c233)
